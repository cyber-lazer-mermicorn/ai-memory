# AI Memory
## Long-Term Memory for AI Agents

Give your AI agents persistent memory across sessions. Remember, learn, and evolve.

**Live:** https://ai-memory.vercel.app

---

## What This Demonstrates

### Persistent Memory
- Cross-session memory
- Knowledge graph storage
- Context retrieval

### Memory Types
- Episodic (events)
- Semantic (facts)
- Procedural (skills)

### Learning
- Pattern recognition
- Knowledge accumulation
- Adaptive behavior

---

## Getting Started

```bash
git clone https://github.com/cyber-lazer-mermicorn/ai-memory.git
cd ai-memory
npm install
npm run dev
```

---

## Memory Architecture

| Type | Storage | Use Case |
|------|---------|----------|
| Episodic | Vector DB | Past conversations |
| Semantic | Graph DB | Facts and relationships |
| Procedural | File System | Learned skills |
